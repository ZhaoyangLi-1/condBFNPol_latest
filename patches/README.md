# Vendored env patches for headless paper-style rendering

The 8-env rollout videos under `videos/` were generated by patching three
vendored environment files so that they:
- support `render(mode="rgb_array")` headlessly (work with `SDL_VIDEODRIVER=dummy`)
- accumulate a fading trail of past positions across the episode, matching the
  trajectory-style visualization in the original PAMDP papers

The vendored repos are excluded from this release (`.gitignore` lists
`_external/`); after cloning them as described in the top-level README,
copy these patched files over the originals.

| Patched file | Target path |
|---|---|
| `dlpa_multiagent_rendering.py` | `_external/DLPA/multiagent/rendering.py` (pygame port; no pyglet/X needed) |
| `gym_platform_env.py` | `_external/self-supervised-rl/RL_with_Action_Representation/HyAR/gym-platform-master/gym_platform/envs/platform_env.py` |
| `gym_goal_env.py` | `_external/self-supervised-rl/RL_with_Action_Representation/HyAR/gym-goal-master/gym_goal/envs/goal_env.py` |

```bash
cp patches/dlpa_multiagent_rendering.py _external/DLPA/multiagent/rendering.py
cp patches/gym_platform_env.py _external/self-supervised-rl/RL_with_Action_Representation/HyAR/gym-platform-master/gym_platform/envs/platform_env.py
cp patches/gym_goal_env.py _external/self-supervised-rl/RL_with_Action_Representation/HyAR/gym-goal-master/gym_goal/envs/goal_env.py
```

Then render with `SDL_VIDEODRIVER=dummy BFN_NATIVE_RENDER=1 python scripts/render_rollouts.py …`
or via the SLURM templates under `jobs/render_*.job`.
